# TunnelVerse demo

A demo of TunnelVerse, a training and certification platform for tunnel construction. It runs entirely in your browser: open https://sanketsalvinitk.github.io/tunnelverse-demo/

This repository only holds the built website. All lesson content is a draft written with AI assistance and approved for pilot use only; it has not been reviewed by a tunnelling expert and is not for use on site. Photos are from Wikimedia Commons under their stated licences (see the Credits page).
