# Curriculum sources

Collected 16 Oct 2026 for the DRAFT lesson plans. Each lesson in `content/lesson-plans/` cites these by code (S1…S19) and, where a source has numbered criteria, by criterion (e.g. "S1 MIN/N1208 PC3").

**How they are used.** Sources set _what_ each role must be able to do. The lesson plans paraphrase their published criteria and outlines as learning objectives; nothing is copied as teaching text. Paid standards (BS, IS) must be bought before quoting. Check the current version of each source before writing lessons from it.

## S1

**Qualification File — Jumbo Drill Operator (NSQF Level 4)**

- Issued by: Skill Council for Mining Sector (SCMS), NCVET, India
- Reference: QG-04-MG-04058-2025-V2-SCMS, v4.0, ratified 43rd NSQC meeting 8 May 2025
- Link: <https://www.nqr.gov.in/qualification/file/Q_File_Jumbo%20Drill%20Operator_02.07.2025.pdf>
- Used for: Operator path backbone: MIN/N1208 Prepare jumbo drill machine for operation (150 h), MIN/N1209 Perform operations on jumbo drill (150 h), MIN/N1210 Routine maintenance and troubleshooting (90 h), DGT/VSQ/N0101 Employability skills, elective MIN/N1702 HSE for underground metalliferous mines; 70% aggregate pass mark.
- Used in paths: Jumbo operator, Site engineer (drill and blast), Shift supervisor, Student foundations
- Note: Written for underground mines (DGMS context). Adapt mining-specific items for civil tunnelling.

## S6

## Coverage gaps

- **Machine-specific operator training** (Epiroc, Sandvik and others) is not publicly documented; ask the pilot contractor's supplier for the operator manual and training syllabus of the actual jumbo model, and add it as the "Machine-specific supplement" lesson.
- **Civil-tunnelling qualifications in India.** No NSQF qualification for civil tunnelling roles was found; the mining-sector files (S1, S2) are the closest and are adapted using S6, S7 and S10.
- **Site engineer** has no single national standard; the plan combines university and industry courses (S13–S16) with Indian standards (S7–S9).
